# BOURN design and mobile decisions

## Direction
Warm travel editorial: original imagery, generous whitespace, restrained motion and a planner-first product. Black Tomato informs the inspiration-to-human-conversation flow; no proprietary page is copied.

## Tokens
Ivory #F4F1EB canvas; olive #252922 text/actions; brass #956F42 focus/emphasis. Inter 400/500/600 for UI/body, Libre Baskerville 400 for headings. Fonts bundled through Fontsource, retaining package licenses. No runtime Google Fonts requests.

## Mobile
Responsive web with home-screen metadata, not a native store app. Single-column controls, 44px primary targets, 16px form text, visible focus, reduced motion. No offline promise. A native app should follow validation of repeated traveller usage.

## Flow
Discover → dates → group → interests → stay/transport → budget → notes → result → brief. Illustrative costs; no invented inventory or testimonials.
